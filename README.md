# Operating-System-Projects
A collection of projects from my operating systems class

Briefly summarize The Gaming Room client and their software requirements. Who was the client? What type of software did they want you to design?
In these series of projects I had to create fragments of code for a company called The Gaming Room for thier new game Draw it or Lose it, essentially 
I needed to create a web based program in java that could save user names, passwords, we did not do any of the games code in depth.

What did you do particularly well in developing this documentation?
I feel like I was very clear and concise in laying out what we can do versus what our client wanted, in this project we could do what the cleint wanted
in full as well as add some suggections for smoother operation.

What about the process of working through a design document did you find helpful when developing the code?
I found that the design document in whole gave me a lot of direction on what I needed to do, I used the clients requirements as a kind of lattice work to build my code on.

If you could choose one part of your work on these documents to revise, what would you pick? How would you improve it?
I would revise some of the security points and recommendations I made, at the moment I am not entirely literate on the finer points of seoftware security and I would like to revise these points when I am more familiar.

How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?
Basically I read the clients requirments and then thought about if I was a user what I would like to see in this app, I then coded in the mindset of the user.

How did you approach designing software? What techniques or strategies would you use in the future to analyze and design a similar software application?
As stated above, I used the clients requests as a framework and I tried to think about what I would want as a user in this app, I also utilized OOP in this project which helps tremendously with modularity, I will probably continue these methods in coding in the future unless something requires me to change.
